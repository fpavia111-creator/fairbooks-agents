# Real public bank files through Fairbooks Bank Reconciliation (2026-11-19)

Made by `node scripts/realdata.mjs` (downloads with `--download` into the git-ignored `_realdata/`). Each file is read by `recon_read_statement` and, separately, by a small re-count in the script that sums the transaction amounts and reads the balances the file states. Details per file: `realdata-2026-11-19.json`.
